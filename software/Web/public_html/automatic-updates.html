Automatic Updates & Privacy

Automatic Software Updates

SigCore UC periodically checks for available software releases. When an eligible update is published, the device downloads and installs it automatically. The update request originates from SigCore UC.

What Does SigCore UC Send During an Update?

Sent

  • Device serial number (DSN)
  • Hardware revision
  • Software version
  • Timestamp
  • Update status

Not sent

  • Measurements
  • Input and output states
  • Device configuration
  • Operational logs

Update status information helps identify whether a software release was downloaded, prepared, or installed successfully, or whether an update failed.

Manufacturer Access

The automatic-update system does not provide en Z em with a remote login or remote-control connection to your SigCore UC. We do not use the update system to read measurements, inspect your I/O states, retrieve configuration settings, or collect operational logs.

en Z em publishes software releases that devices may install automatically. Publishing a software update is distinct from connecting to, or issuing operational commands to, a particular customer's controller.

Network Requests

As with other internet requests, connections to the update server can expose the device's public network IP address to the hosting infrastructure. This is separate from the device information listed above.

Questions

For questions about device updates or transmitted information, contact en Z em. For broader website and information practices, read our Privacy Policy.
