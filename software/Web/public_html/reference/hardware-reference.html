Get started

SigCore UC brings together eight relay outputs, eight digital inputs, four analog inputs, and four analog outputs in one network-connected controller. Use the Dashboard to see device information, Control to view and operate channels, Properties to tailor channels to your application, and Device to manage device settings.

8 relays8 digital inputs4 analog inputs4 analog outputs

For a new installation

  1. Position the controller where its terminals and network connection are accessible.
  2. Plan which devices and sensors will connect to each channel. Note the channel numbers before wiring.
  3. Connect the controller to its 5 V DC supply and to your local network.
  4. Open the device website or connect using the SigCore UC Control Panel.
  5. Set up channel Properties, connect one signal at a time, and verify each channel in Control.

About the relay terminals: The controller is powered by 5 V DC, but relay contacts can switch an independently supplied circuit. Treat any externally connected voltage according to the circuit actually attached to the contacts.

Connect to the device

From a web browser

  1. Connect SigCore UC to your local network.
  2. In a browser on the same network, open the device's assigned IP address, for example http://192.168.0.103. This is an example address, not a factory default.
  3. The Dashboard should display the device identity and status. Open Control to see channel values.

From the Control Panel

Launch the SigCore UC Control Panel, discover the unit on your network, select it, and connect. Confirm its serial number before modifying settings. See the Control Panel Reference for individual controls and dialog explanations.

If the address has changed, use device discovery or check the address assigned by your router rather than relying on a previously saved IP address.

Find your connections

Identify the connector group and channel number printed on your device before inserting the corresponding terminal plug. The four I/O groups have different electrical functions:

DI1–DI8 — digital inputsSwitches and other on/off signalsON/OFF indication
AI1–AI4 — analog inputsVoltage or current measurementsNumeric live values
AO1–AO4 — analog outputsVoltage or PWM control signalsOutput values and controls

Keep a simple channel list for the installation. A name such as “Tank Level” or “Pump Enable” makes later operation much easier than remembering a channel number.

Switch a device with a relay

Use a relay when SigCore UC needs to open or close an independently powered circuit. Each of the eight relays has three contacts:

TerminalWhat it means
COMCommon contact
NONormally open relative to COM when the relay is not energized
NCNormally closed relative to COM when the relay is not energized

Typical use

  1. Choose the relay channel that will operate the external device.
  2. Connect the external circuit through COM and NO if you want the circuit normally open, or COM and NC if you want it normally closed.
  3. Open the relay's Properties and give it a meaningful name. Set its startup and fail-safe behavior for your application.
  4. Use Control to change the relay state and confirm that the intended external circuit responds.

The contacts do not provide their own supply voltage; power for the controlled circuit comes from that circuit. The relay's published rating is 120 VAC / 10 A; ensure the specific load is within its permitted rating. Where an external circuit carries mains voltage, that circuit still requires appropriate handling and protection.

Remember: Relay inversion can change how ON and OFF are presented in software. When verifying an installation, check the actual COM–NO or COM–NC behavior, not only the on-screen label.

Read an on/off signal

Use a digital input for a signal that has two meaningful states, such as a sensor's active/inactive output or a switch wired to provide the appropriate input voltage.

Connect and verify

  1. Choose DI1–DI8 and identify the corresponding input and ground/reference terminals using the markings on your unit.
  2. Connect a signal that produces the required voltage levels relative to that reference.
  3. Open Control, operate the sensor or switch, and observe the corresponding DI indicator.
  4. If the expected logical indication is opposite, adjust Inverted in that channel's Properties.
  5. For mechanical switches that bounce, use the channel's debounce setting as needed.
Voltage at inputInterpreted state
1 V or lessOFF
2 V or moreON
Between 1 and 2 VNot a defined logic level

Inversion changes the logical indication, not the physical voltage required by the input. An open contact does not automatically create an ON signal; the connected circuit must supply an appropriate signal.

Measure an analog signal

Choose an analog input for a sensor that produces a continuously varying signal. SigCore UC provides four channels, each configured independently in Properties.

For a voltage-output sensor

  1. Identify the sensor's output range. Supported Rev B modes include 0–5 V and 0–500 mV.
  2. Connect the signal and its appropriate reference to the selected analog input.
  3. Select the corresponding measurement range in the channel's Properties.
  4. Open Control and check the reading against a known signal or sensor condition.
  5. Set the display name, units, precision, averaging, or calibration if the application requires it.

For a 4–20 mA signal

  1. Use an appropriate external current-loop supply and wire the transmitter according to its own instructions; SigCore UC is not assumed to provide loop power.
  2. Connect the measurement loop to the appropriate channel terminals.
  3. Select 4–20 mA in Analog Input Properties.
  4. Verify the reading at a known transmitter value before relying on it.

A sensor with a 0–10 V output needs an external voltage divider or other suitable conditioning for the Rev B input. Do not connect a 10 V signal directly while the input is configured for a 0–5 V range.

For steady readings: Averaging can smooth noisy measurements; calibration can correct known measurement errors. Neither changes the physical input's permissible range.

Send an analog output

Each of the four analog outputs can supply a configurable control signal. Choose the mode expected by the receiving device: 0–5 V voltage output or PWM.

Set up an output

  1. Identify the control signal required by the equipment you are connecting.
  2. Open the selected analog output's Properties and choose the appropriate mode.
  3. Configure any units or output scaling used by your application.
  4. Connect the output to the receiving device's compatible signal input and reference.
  5. Use Control to command a test value and verify the external response.

PWM is a pulsed signal, not a steady analog voltage. Use voltage mode for equipment expecting a continuous control voltage unless that equipment specifically accepts PWM.

Save channel Properties

Properties personalize the channels so that Control reflects your installation. Channel names help operators understand what each point does. Other Properties affect the way a channel operates or is displayed.

Change one channel at a time, save its Properties, then confirm the result on the Control page. For descriptions of each dialog field, see the Control Panel Reference.

Network and device settings

The Device page contains system and network settings. The Dashboard shows the currently reported network information, which may differ from a saved static address when DHCP is enabled.

Use DHCP

Leave DHCP enabled if your router should assign the device's address automatically. To find the unit later, use discovery, its hostname (when your network supports name resolution), or the router's device list.

Use a static address

Disable DHCP for the applicable interface, enter the address, subnet mask, gateway, and DNS settings appropriate to your network, and apply them. An incorrect address can make the website unreachable from your computer until the network settings are corrected.

Network Properties also include Wi-Fi configuration. Keep the saved Wi-Fi password when making unrelated changes; change it only when you intend to replace it.

Check your installation

Before putting the device into regular operation, verify the actual connected signals rather than relying on names or assumptions:

  1. Confirm that the Dashboard identifies the intended unit and that the device is ready.
  2. Change each connected digital signal and confirm the correct DI channel changes state.
  3. Operate each connected relay and check that the intended contact path operates the load.
  4. Compare analog input readings with a known signal or operating condition.
  5. Command each analog output through a suitable test range and confirm the receiving equipment reacts correctly.
  6. Review channel names and Properties so the displayed controls match the installation.
  7. Verify the device remains reachable at its intended network address.

Where a circuit could actuate equipment, perform the first test under controlled conditions appropriate to that equipment.

For system events and diagnostic messages, open Logs. For detailed configuration controls, use Properties. If an interface is still not responding as expected, record the serial number, channel, settings, and observed behavior before contacting support.
